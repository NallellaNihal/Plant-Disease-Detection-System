# 🌿 Smart Plant Disease Detection System

AI-powered plant disease detection system using CNN and Transfer Learning for identifying plant leaf diseases from images.

---

## 📌 Project Overview

Plant diseases significantly affect agricultural productivity and food security. Early disease detection helps farmers take preventive measures and reduce crop loss.

This project uses **Deep Learning**, **Convolutional Neural Networks (CNN)**, and **Transfer Learning** to classify plant leaf images into healthy and diseased categories.

The system provides:
- Disease prediction
- Confidence score
- Basic treatment recommendation
- User-friendly web interface using Streamlit

---

## 🚀 Features

- 🌱 Plant leaf disease classification
- 🧠 Deep Learning based prediction
- 📷 Image upload support
- 📊 Confidence score display
- 💡 Disease prevention recommendations
- 🌐 Streamlit web application
- ⚡ Fast and lightweight interface
