# Dataset Folder

Add your images in this format:

```text
dataset/train/ClassName/
dataset/validation/ClassName/
dataset/test/ClassName/
```

Example:

```text
dataset/train/Healthy/
dataset/train/Black_Rot/
dataset/train/Leaf_Blight/
dataset/train/Powdery_Mildew/
```

The dataset images are not included in this ZIP because datasets are usually large.
